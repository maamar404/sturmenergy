# Sturm Energy — Corporate Product Showcase Website

**Live Website:** [https://sturmenergy.freehosting.dev](https://sturmenergy.freehosting.dev)

## Overview
A corporate product showcase website built on WordPress for **Sturm Energy** (Sturm Oils), designed to organize and present industrial lubricating oils and grease product lines with clear category navigation and brand-aligned visuals.

---

## Key Contributions & Architecture

* **Theme Selection & Brand Customization:** Evaluated base themes compatible with lightweight corporate layouts and customized typography, color palettes, and visual hierarchy to match the Sturm Energy brand identity.
* **Child Theme Architecture (`elementor-child`):** Implemented a dedicated child theme to safely isolate custom PHP templates, stylesheet overrides, and `functions.php` hooks—ensuring full update safety for the parent theme and WordPress core.
* **Dynamic Product & Category Templates:** Developed category-specific PHP templates integrated with **Advanced Custom Fields (ACF)** to dynamically render category banners, technical product specifications, and structured product grids.
* **Plugin Selection & Optimization:** Configured a minimal, purpose-built plugin stack to handle layout building, custom fields, and lead capture without bloating page load times.

---

## Tech Stack & Plugin Ecosystem

| Layer | Tools & Technologies |
|---|---|
| **CMS & Core** | WordPress, PHP, HTML5, CSS3, JavaScript |

| **Custom Data** | Advanced Custom Fields (ACF) |
| **Forms & Lead Capture** | WPForms |
